# Прогнозирование спроса с помощью машинного обучения

## Описание проекта

Проект посвящён прогнозированию ежедневных продаж товаров на основе исторических данных розничной торговли.

Основная цель — построить и сравнить модели машинного обучения, разработать признаки для временных рядов и подобрать гиперпараметры для улучшения качества прогнозирования.

В проекте используется датасет **Store Sales – Time Series Forecasting** от Corporación Favorita.

## Задачи проекта

- Исследование исторических данных о продажах.
- Создание календарных признаков и признаков на основе прошлых продаж.
- Построение базовой модели для сравнения.
- Обучение и сравнение CatBoost и LightGBM.
- Подбор гиперпараметров с помощью Optuna.
- Оценка качества моделей с использованием MAE и RMSE.

## Данные

Датасет содержит информацию о ежедневных продажах товаров в разных магазинах.

Основные признаки:

- `date` — дата наблюдения.
- `store_nbr` — идентификатор магазина.
- `family` — категория товаров.
- `sales` — объём продаж.
- `onpromotion` — количество товаров по акции.

Исходные CSV-файлы не включены в репозиторий.

Скачать датасет можно на Kaggle: [Store Sales – Time Series Forecasting](https://www.kaggle.com/competitions/store-sales-time-series-forecasting/data).

Для запуска ноутбука необходимо скачать данные и разместить нужные CSV-файлы в директории проекта.

## Подход

### 1. Feature Engineering

Были созданы следующие группы признаков:

- **Календарные:** день недели, день месяца, месяц, год и номер недели.
- **Лаговые:** продажи за 1, 7, 14 и 28 дней до текущей даты.
- **Скользящие средние:** средние продажи за последние 7 и 28 дней.

Лаговые признаки и скользящие средние рассчитывались отдельно для каждой комбинации магазина и категории товаров. При расчёте скользящих средних использовался сдвиг на один день, чтобы не включать текущее целевое значение.

### 2. Разделение данных

Данные сортировались по времени. Последние 30 дней использовались для валидации, а более ранние наблюдения — для обучения.

Такой подход учитывает временную структуру задачи и позволяет избежать случайного перемешивания наблюдений между обучающей и валидационной выборками.

### 3. Обучение моделей

**Baseline — Lag-7**

Базовый прогноз, в котором продажи предсказываются на основе значений за аналогичный день предыдущей недели.

**CatBoost Regressor**

Градиентный бустинг, обученный на календарных, категориальных, промо-, лаговых признаках и скользящих средних.

**LightGBM Regressor + Optuna**

Градиентный бустинг с подбором гиперпараметров с помощью Optuna. В качестве целевой метрики оптимизации использовалась MAE на валидационной выборке.

## Результаты

| Модель | MAE ↓ | RMSE ↓ |
|---|---:|---:|
| Baseline (Lag-7) | 84.63 | 310.16 |
| CatBoost | 62.94 | 207.79 |
| LightGBM + Optuna | **55.97** | **193.87** |

Чем ниже значения MAE и RMSE, тем меньше ошибка прогнозирования.

Лучший результат показала модель LightGBM с подобранными гиперпараметрами. По сравнению с baseline значение MAE снизилось примерно на 33.9%.

## Запуск проекта

1. Склонировать репозиторий.
2. Установить зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Скачать датасет с Kaggle и разместить необходимые CSV-файлы в директории проекта.
4. Открыть `demand_forecasting.ipynb` в Jupyter Notebook или JupyterLab.
5. Выполнить ячейки ноутбука по порядку.
